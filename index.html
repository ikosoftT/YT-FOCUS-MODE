Install in 60 seconds

Four steps. No account. No BS.

No Chrome Web Store. Load it directly — takes under a minute.

1

Download the extension

Click the button below to download the yt-free-distraction.zip file to your computer.

2

Unzip the file

Find the downloaded zip, right-click it and choose "Extract All" (Windows) or just double-click (Mac). You'll get a folder called yt-focus-extension.

3

Open Chrome Extensions

In Chrome, go to chrome://extensions — or open the menu → More Tools → Extensions. Turn on Developer mode using the toggle in the top-right corner.

4

Load the extension

Click "Load unpacked" and select the yt-focus-extension folder you unzipped. Done — the icon appears in your toolbar instantly.

5

Go to YouTube and enjoy the silence

Open youtube.com — your homepage will be replaced with a clean focus screen. Click the extension icon anytime to toggle features on or off.
